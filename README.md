# Portfolio de Cristian Rodríguez

Demo en vivo: https://crisrcportfolio.netlify.app

Descripción
-----------

Portfolio personal construido con Astro y Tailwind CSS para mostrar proyectos, experiencia y habilidades técnicas.

Tecnologías
-----------

- Astro
- Tailwind CSS
- TypeScript
- Node.js / npm

Características
---------------

- Sitio estático rápido y accesible.
- Componentes reutilizables en `src/components`.
- Diseño responsivo con Tailwind.

Estructura relevante
--------------------

- Página principal: [src/pages/index.astro](src/pages/index.astro)
- Layout principal: [src/layouts/Layout.astro](src/layouts/Layout.astro)
- Componentes: [src/components/Header.astro](src/components/Header.astro), [src/components/Footer.astro](src/components/Footer.astro)
- Configuración del proyecto: [package.json](package.json)

Instalación y uso
-----------------

1. Instala dependencias:

```bash
npm install
```

2. Ejecuta en desarrollo:

```bash
npm run dev
```

3. Construir para producción:

```bash
npm run build
npm run preview
```
